
# Zen Tabs Organiser

Sort your browser tabs into groups using AI or domain-based grouping in one click.

## Features

- Sort: Groups all open tabs via AI (OpenAI, Gemini, Ollama, Mistral) or by domain
- Clear: Closes ungrouped, unpinned tabs with animation
- Auto-colors: 12-color curated palette
- Auto-icons: Contextual icons (requires Advanced Tab Groups)
- Workspace-aware: Only affects the active workspace
- Collapse animation: Smooth wave effect
- Settings UI: Full configuration in Zen Mods preferences

## AI Configuration

1. Open about:preferences, select Zen Tabs Organiser
2. Pick an AI Provider (Gemini, Ollama, Mistral, or OpenAI)
3. Enter your API Key
4. Optionally set a custom Model name
